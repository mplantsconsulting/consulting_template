# _archive — 退避した分析

`中断` になった分析、および更新版が出て参照されなくなった分析を、`.md` と成果物フォルダごと移す場所。

- **削除はしない。** 過去の判断が何を根拠にしていたかを追えなくしないため。
- 移動時に、対象 `.md` の冒頭へ理由を1行足す。
  - 中断の場合: `> 中断（YYYY-MM-DD）: <理由>`
  - 更新版が出た場合: `> 更新版: <新ファイルへのリンク>`
- [INDEX.md](../../INDEX.md) の行は消さず、リンク先をここに張り替える。
- **ここの数値を資料へ新規に転記しない。** 参照は可、転記は不可。
