`docs/INDEX.md` を実際のファイルと突き合わせて更新してください。

## 手順

1. `docs/` 配下のファイルを列挙する（`_TEMPLATE*` `README.md` は索引の対象外）
2. 各ファイルの冒頭からステータス・最終更新日を読む
3. `docs/INDEX.md` の記載と突き合わせ、以下を検出する

   | 検出するもの | どうするか |
   |---|---|
   | INDEX にない実ファイル | 追記する |
   | INDEX にあるが実ファイルがない | **削除せず報告する**（移動・改名の可能性） |
   | ステータスの不一致 | 実ファイル側を正として INDEX を直す |
   | `_archive/` へ移動されたもの | 行を消さず、リンク先を張り替える |

4. 「最終更新」行を更新する。**前回分は「前回更新」として残す（削除しない）**
5. 更新内容は、ファイル名だけでなく**結論の要点**まで書く
   （この行を読むだけで案件の状況が分かる状態を保つ）

## 併せて点検すること

- [ ] `完了` でない分析の数値が、`docs/presentations/` に転記されていないか
- [ ] `【仮説・未確認】` が付いた記述が、`presentations/` や `ideas/` の根拠になっていないか
- [ ] リンク切れ（相対パスの誤り、移動済みファイルへの参照）がないか
- [ ] `docs/analysis/<担当者名>/ANL-NNN_*/` のフォルダに、`.md` の図表一覧に載っていないファイルが残っていないか

## 最後に報告すること

- 追記・修正した行数
- **実ファイルが見つからなかった INDEX の行**（削除せず報告する）
- 上記の点検で見つかった問題
- 見つかったリンク切れ

INDEX の更新は行って構いませんが、**それ以外のファイルの内容は勝手に変更しないでください。**
